# Contributing to Warehouse Robot Coordination Arena

1. Fork or clone the repository and create a feature branch (`git checkout -b feat/your-feature`).
2. Install dependencies (`npm install`) and verify the simulator runs (`npm run dev`).
3. Ensure all Space-Time A* unit tests pass before committing (`npm test`).
4. Use clear conventional commit messages (`feat:`, `fix:`, `docs:`, `test:`).
5. Open a Pull Request for review by Team ByteForge.
